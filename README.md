# GAMES
A fast-paced browser-based reaction game built with HTML, CSS, and JavaScript. The player must click moving targets within a limited time to score points. The game tests speed, accuracy, and reflexes.
🚀 Features
Simple and responsive UI design
Random target spawning system
Score tracking system
Countdown timer (30 seconds)
Smooth animations and fast gameplay
Works on all modern browsers (mobile & desktop)
🧠 How to Play
Click the red targets as fast as possible before they disappear. Each successful click increases your score. The game ends when the timer reaches zero.
🛠️ Tech Stack
HTML5
CSS3
JavaScript (Vanilla)
